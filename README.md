# 🎓 Student Placement Management System

A full-stack Student Placement Management System built to streamline campus recruitment. Features student tracking, company-wise placement records, and placement status dashboard.

## 🚀 Features
- Student Registration & Login
- Company Management
- Placement Tracking
- Admin Dashboard
- Placement Status & Reports
- Secure Authentication

## 🛠️ Tech Stack
**Frontend:** React, Vite, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB
**Version Control:** Git & GitHub
